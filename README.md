# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview
This project is an interactive Power BI dashboard built to analyze mobile sales performance. It provides insights into sales trends, customer behavior, payment methods, product performance, and regional sales distribution.

## 🚀 Key Features
- 📊 Total Sales KPI
- 📦 Total Quantity Sold
- 💰 Average Selling Price
- 🧾 Transaction Count
- 🗺️ Sales by City (Map Visual)
- 📅 Monthly Sales Trend
- 💳 Payment Method Analysis
- 📱 Top Mobile Models
- ⭐ Customer Rating Analysis
- 📆 Daily Sales Trend
- 🎛️ Interactive Slicers (Brand, Mobile Model, Payment Method, Month)

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📈 Dashboard Insights
- Identify top-performing mobile brands.
- Compare payment method preferences.
- Analyze monthly and daily sales trends.
- Track sales performance across different cities.
- Monitor customer ratings and product performance.
